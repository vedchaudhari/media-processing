# 18. Ask-AI (Transcript-Grounded Q&A / RAG)

**Status:** ✅ Done

- **New endpoint:** `POST /api/videos/:videoId/ask` — retrieval-augmented question answering scoped to a single video's transcript.
- **RAG flow (`askVideo`):**
  1. Embed the question in `"query"` mode via `EmbeddingService`.
  2. Vector-search the video's dimension-scoped Qdrant collection, filtered by `videoId` (top 4 chunks).
  3. Relevance filter — keep the best match plus any others scoring ≥ 0.4.
  4. Build a timestamped context block and ask the provider.
  5. Return the answer plus **de-duplicated, chronologically sorted source segments** (with start/end times) so the UI can deep-link into the video.
- **Provider contract extended:** `AIProvider` gains `askQuestion(context, question)`; Gemini, Ollama, and OpenAI all implement it. `buildAskPrompt` instructs strictly-grounded answers — a `"couldn't find the answer"` fallback, no outside knowledge, and no reasoning/monologue.
- **Answer sanitizing:** `cleanThinkingTags` strips `<think>…</think>` blocks and stray "Hmm… Final decision:" monologue that local reasoning models leak; `AIService.askQuestion` applies it to every answer.
- **Graceful degradation:** Returns a friendly message (never a 500) when the video's `vectorIndex` is still `pending`/`processing`, has `failed` or been `skipped`, or when the Qdrant collection doesn't yet exist.
