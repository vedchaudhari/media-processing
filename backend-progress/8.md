# 8. Storage Service (MinIO Operations)

**Status:** ✅ Done

- **Bucket management:** Auto-creates the video bucket on startup if it doesn't exist
- **Public-read policy:** Sets an S3-compatible bucket policy granting anonymous `GetObject` on `*/hls/*` and `*/thumbnail.jpg` paths — originals stay private
- **Content-type mapping:** `.m3u8` → `application/vnd.apple.mpegurl`, `.ts` → `video/mp2t` for correct browser/player handling
- **Operations:**
  - `objectExists` — HEAD check to confirm upload landed
  - `downloadObject` — pulls file to local disk
  - `uploadObject` — pushes single file with content-type
  - `uploadDirectory` — recursive directory upload preserving structure (used for HLS output)
  - `removeObjects` — batch delete for rollback cleanup
