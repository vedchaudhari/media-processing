# 5. Inspection Worker (FFprobe Metadata Extraction)

**Status:** ✅ Done

- Downloads original video from MinIO to a temp directory
- Runs `ffprobe` (via `execFile`, no shell) to extract JSON metadata
- Parses video stream (width, height, codec, frame rate) and audio stream (codec)
- Parses format-level data (duration, bitrate)
- Saves metadata to the video doc, sets status to `inspected`
- Enqueues the video into the **planner queue**
- On failure: marks video as `failed` with `failedStage: "inspection"` and error message
- Temp files always cleaned up in `finally` block

### Key Files

- `src/workers/inspection.worker.ts`
- `src/services/ffprobe.service.ts`
