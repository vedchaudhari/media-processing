# 9. Video List & Playback API

**Status:** ✅ Done

- **`GET /api/videos/get-videos`** — Returns all videos (newest first) with lightweight projection: `id, title, status, progress, createdAt`
- **`GET /api/videos/:videoId/play`** — Returns the HLS playback URL for a completed video
  - Only serves `completed` videos with a `masterPlaylist` set
  - Returns `409` with current status/progress if still processing or failed
  - Constructs public URL: `<MINIO_PUBLIC_URL>/<bucket>/<masterPlaylist path>`
