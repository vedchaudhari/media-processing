# 11. Graceful Shutdown

**Status:** ✅ Done

- Handles `SIGINT` and `SIGTERM` signals
- **Shutdown order:** Stop HTTP server → drain BullMQ worker (waits for active job) → close queues → disconnect Mongoose → quit Redis
- **Idempotent:** Second signal during shutdown is ignored
- **Force timeout:** 30s safety net — if graceful close hangs, force `process.exit(1)`
- Each process (API server, each worker) registers its own resources

- `src/config/shutdown.ts`
