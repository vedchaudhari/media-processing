# 1. Project Setup & Configuration

**Status:** ✅ Done

- **Stack:** Node.js + TypeScript + Express v5
- **Build/Dev:** `tsx watch` for hot-reload, `tsc` for production build
- **Package type:** ES Modules (`"type": "module"`)
- **Environment:** Centralized `envconfig.ts` loads `.env` via dotenv — all modules import from here, never `process.env` directly
- **Docker Compose:** MinIO container (ports 9000/9001) with persistent `./data` volume

### Key Files

- `src/config/envconfig.ts` — single env object (port, mongo, redis, minio, transcode settings)
- `src/config/db.ts` — MongoDB connection via Mongoose
- `src/config/redis.ts` — ioredis connection (shared by BullMQ)
- `src/config/minio.ts` — MinIO client + bucket name export
- `docker-compose.yml` — MinIO service
- `tsconfig.json`, `package.json`
