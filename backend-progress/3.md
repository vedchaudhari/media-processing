# 3. Video Upload API (Presigned URL Flow)

**Status:** ✅ Done

- **`POST /api/videos/initiate-upload`** — Creates a video doc (status `uploading`), generates a 1-hour presigned PUT URL from MinIO, returns `videoId + uploadUrl` to client
- **`POST /api/videos/:videoId/complete-upload`** — Client calls after uploading the file directly to MinIO
  - Validates ObjectId
  - **Idempotency guard:** only `uploading` status can be completed; repeat calls are no-op
  - **Server-side verification:** checks the object actually exists in MinIO before proceeding
  - **Atomic CAS:** uses `findOneAndUpdate` with `{ status: "uploading" }` filter to prevent race conditions between duplicate requests
  - Enqueues the video into the **inspection queue** on success

- `src/controllers/video.controller.ts` — `initiateUpload`, `completeUpload`
- `src/routes/video.routes.ts`
