# 13. Thumbnail Generation

**Status:** ✅ Done

- **Parallel Ingestion Flow:** Dispatches both the Planner (`plan-video`) and Thumbnail (`generate-thumbnail`) jobs in parallel via `Promise.all` immediately following successful inspection.
- **Dedicated Queue & Worker:** Runs asynchronously on a separate `thumbnail` queue, downloading the video to temp space, generating the frame, uploading to storage, and performing cleanup.
- **FFmpeg Frame Extraction:** Service extracts a single frame as JPEG at 25% of the video duration, capped at 640px wide to optimize storage/bandwidth.
- **Non-Blocking Operation:** Design isolates failures in thumbnail generation; errors are logged, but do not set the main video status to `failed` or interrupt the core transcoding workflow.
- **Public-Read Policy:** Dynamically configures the MinIO bucket policy to allow anonymous public access to generated `thumbnail.jpg` assets.
- **API Integration:** Returns the fully resolved `thumbnailUrl` in both `listVideos` (`GET /get-videos`) and `getPlay` (`GET /play/:id`) JSON responses.
