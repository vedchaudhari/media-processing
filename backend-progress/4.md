# 4. BullMQ Job Queue System

**Status:** ✅ Done

- **3 queues:** `inspection`, `planner`, `transcoder` — each backed by Redis via BullMQ
- **Pipeline chaining:** inspection → enqueues planner → enqueues transcoder (each worker hands off to the next queue on success)
- **Shared default job options:** 3 attempts with exponential backoff (5s base), auto-cleanup of completed/failed jobs in Redis
- **Dev runner:** `npm run dev:all` uses `concurrently` to launch API server + all 3 workers in parallel with color-coded logs

### Key Files

- `src/queue/inspection.queue.ts`
- `src/queue/planner.queue.ts`
- `src/queue/transcoder.queue.ts`
- `src/config/queueconfig.ts` — shared retry/cleanup defaults
