# 6. Planner Worker (Rendition Ladder)

**Status:** ✅ Done

- Reads inspected metadata from the video doc
- Generates a rendition ladder based on source height (never upscales)
- **Presets:** 2160p (12 Mbps), 1080p (5 Mbps), 720p (2.8 Mbps), 480p (1.2 Mbps)
- Sources below 480p get a single variant at original height using source bitrate
- Saves `variants[]` array to the video doc, sets status to `planned`
- Enqueues the video into the **transcoder queue**
- On failure: marks video `failed` with `failedStage: "planning"`
- **Unit tests:** 7 test cases covering full ladder, no-upscale, sub-480, missing height
