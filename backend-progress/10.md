# 10. Health Check & Startup Tasks

**Status:** ✅ Done

### Health Check

- **`GET /health`** — Deep health check that verifies all 3 dependencies:
  - **MongoDB:** `mongoose.connection.readyState === 1`
  - **Redis:** `ping()` returns `PONG`
  - **MinIO:** Bucket exists check
- Returns `200 { status: "okay" }` or `503 { status: "degraded" }` with per-service breakdown

### Startup Tasks

- Runs after DB connects, before server starts listening
- **Storage init:** Creates video bucket + sets HLS public-read policy
- Designed to be extended (seeding, caching, etc.)

### Key Files

- `src/index.ts` — health endpoint
- `src/startup/index.ts` — startup runner
