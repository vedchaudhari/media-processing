# 15. AI Summarizer Backend Service & Worker

**Status:** ✅ Done

- **Event-Driven AI Queue:** Triggered immediately when Whisper transcription completes in \`transcript.worker.ts\`, adding a \`"generate-summary"\` job to the new BullMQ \`ai\` queue.
- **Dynamic Provider Switcher:** Implemented a unified \`AIService\` switcher that dynamically instantiates a provider based on \`AI_PROVIDER\` or \`NODE_ENV\`.
- **Three LLM Providers:**
  - **Gemini Provider:** Queries Google's Gemini endpoint (e.g. \`gemini-2.5-flash\`) via \`@google/genai\` SDK, sanitizing markdown JSON fences from response text.
  - **Ollama Provider (Local):** Queries local Ollama API (\`/api/generate\`) in JSON mode with reasoning/thinking disabled (\`think: false\`) and a fallback to parse the \`thinking\` field if reasoning is returned.
  - **OpenAI Provider:** Queries OpenAI's newer Responses API (\`/v1/responses\`) using input prompts and structured json output.
- **Mongoose Schema Extension:** Added \`aiSummary\` schema configuration nested in \`IVideo\` to store summarization details: \`summary\`, \`keyTakeaways\`, \`technologies\`, status, and errors.
- **Graceful Shutdown & Concurrency:** Configured the \`ai.worker.ts\` with bounded concurrency (2) and registered it under graceful shutdown scripts.
- **Concurrently Dev Runner:** Integrated \`"worker:ai"\` script into \`package.json\` to boot automatically alongside other workers via \`npm run dev:all\`.
