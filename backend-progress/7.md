# 7. Transcoder Worker (FFmpeg HLS Encoding)

**Status:** ✅ Done

- Downloads original from MinIO, transcodes each variant to HLS (`.m3u8` + `.ts` segments)
- **Concurrency control:** custom `settleWithConcurrency` limits parallel FFmpeg processes (default 2, configurable via `TRANSCODE_CONCURRENCY`) to respect NVENC session limits / CPU saturation
- **Multi-encoder support:**
  - `h264_nvenc` — NVIDIA GPU (VBR, preset p4)
  - `h264_videotoolbox` — Apple Silicon/Mac GPU
  - `libx264` — CPU software fallback (preset fast)
  - Auto-detected at startup or overridden via `VIDEO_ENCODER` env var
- **Output:** Per-variant: `playlist.m3u8` + `segment_*.ts` segments (6s default). Forces `yuv420p` + stereo audio for browser compatibility
- **Master playlist:** Generated after all variants, references each `<height>p/playlist.m3u8` via relative paths
- **Progress tracking:** Updates BullMQ job progress + persists `progress` (0–100) on the video doc per completed variant
- **Rollback on failure:** Tracks all uploaded object keys; on error, removes partial uploads from MinIO before marking video as failed
- Temp files always cleaned up in `finally`
- **Unit tests:** 3 tests for master playlist generation
