# 14. Automatic Audio Transcription

**Status:** ✅ Done

- **Isolated Python Module:** Set up a clean `python/` subfolder with its own `.venv` and `requirements.txt` containing `faster-whisper`.
- **Parallel Dispatch Flow:** The inspection worker triggers the `transcript` queue in parallel alongside the `planner` and `thumbnail` queues once ffprobe analysis completes.
- **FFmpeg Audio Extraction:** Spawns a sub-process to extract a mono, 16kHz, 16-bit PCM WAV file (`audio.wav`), which is the optimal format for Whisper models.
- **Python-based speech-to-text:** Executes `transcribe.py` using the virtual environment's python runner. The script automatically detects the spoken language and transcribes the audio into structured segments (timestamps + text).
- **Public-Read Policy:** Allows anonymous public access to generated `transcript.json` assets stored on MinIO.
- **Interactive Transcript UI:** Integrates the transcript into the video detail page. Active captions are highlighted in real-time as the video plays, and clicking a segment automatically seeks the video to that timestamp.
