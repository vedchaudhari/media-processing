# Python Transcription Module

This directory contains the Python sub-module responsible for running speech-to-text transcription of media file audio tracks using `faster-whisper`.

## Setup

To set up this module locally, run:

```bash
# Navigate to this directory
cd python

# Create a virtual environment
python3 -m venv .venv

# Install dependencies
./.venv/bin/pip install -r requirements.txt
```
